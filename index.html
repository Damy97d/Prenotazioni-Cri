Prenota un Servizio

Compila il modulo per richiedere visite o certificati.

Come trovare il tuo ID Discord
  1. Apri Discord (app o browser).
  2. Vai su Impostazioni utente (ingranaggio in basso a sinistra).
  3. Nella sezione Avanzate, attiva Modalità sviluppatore.
  4. Chiudi le impostazioni, clicca col tasto destro sul tuo nome e scegli Copia ID utente.
  5. Incolla l'ID nel campo Discord del modulo.

Su mobile: Impostazioni → Aspetto → Modalità sviluppatore, poi tieni premuto sul profilo → Copia ID utente.

Licenza Porto d'Armi

  • ●Dopo 24h dall'anamnestico effettuare il test balistico presso un'armeria di Roma.
